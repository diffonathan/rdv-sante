# Marque — RDV Santé

| Fichier | Usage |
|---|---|
| `logo.svg` | le symbole seul. **Aucune police requise** : formes pures, rendu identique partout. |
| `logo-complet.svg` | symbole + nom, pour un en-tête web où DM Sans est chargée. |
| `logo-mono.svg` | une seule couleur, héritée du texte environnant (`currentColor`). Tampon, gravure, fax, fond coloré. |

## Couleurs

| Rôle | Valeur |
|---|---|
| Vert (marque, action) | `#00B67A` — dégradé `#00C88A` → `#068A5C` |
| Or (valeur, progression) | `#F9A825` |
| Fond nuit | `#0a0a0c` |

Le **vert** et non le bleu : c'est un produit de santé. Le bleu `#0781FE`
appartient à la charte ConfluenceTerminal.

## Le symbole

Une croix médicale entourée d'un arc doré **ouvert**. La croix dit le soin ;
l'arc dit la file qui avance, et son ouverture dit que le tour suivant reste à
venir. Deux barres seulement, épaisses et arrondies : à 16 px dans un onglet,
tout détail interne devient une tache.
